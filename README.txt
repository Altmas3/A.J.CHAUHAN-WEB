A.J CHAUHAN AUTO — demo website
================================

FILES
- index.html: all website sections/pages (Home, About, Vehicles, Services, Gallery, Contact)
- style.css: responsive styling
- script.js: mobile navigation and WhatsApp enquiry form

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Internet is needed for the online vehicle photos and Google Fonts.

BEFORE PUBLISHING
1. Open script.js and set BUSINESS_PHONE to your WhatsApp number in international format, digits only. For India, start with 91 (no +, spaces, or dashes).
2. Set BUSINESS_ADDRESS in script.js.
3. Replace sample vehicle/gallery photos with photos of your actual showroom and vehicles.
4. Update the demo wording, brands, prices, opening hours, and services with accurate details.
5. The enquiry form uses WhatsApp after the number is configured; it does not save submissions to a database.

FREE HOSTING
You can publish the static website using GitHub Pages or Netlify. The free plan generally provides a platform subdomain; a custom domain usually costs extra.
